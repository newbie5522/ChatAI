## 状态枚举

`READY` / `IN_PROGRESS` / `IN_REVIEW` / `BLOCKED` / `DONE` / `PAUSED` / `DESIGN-ONLY` / `NOT_STARTED`

- `DONE`：代码已合并到 main、CI 通过、验收证据存在、回滚方式明确
- `PAUSED`：曾被 R0 撤销，等待 P0 完成后进入 P1 重新执行
- `IN_REVIEW`：PR 已提交，等待非作者审核
- `BLOCKED`：被其他 Issue 阻塞，无法启动

## 总控规则

- 开始或结束任务时同步更新本表。
- Issue 与本表冲突时，以 Issue/PR 的最新可验证事实为准，并立即修正本表。
- DONE 必须同时满足：代码已合并、CI 通过、验收证据存在、回滚方式明确。
- REVERTED 表示曾有实现但已被撤销，等待按新节点要求重做。
- 不得将 mock 测试、文档声明或未接入主流程的代码当成完成证据。
- 从 G0 起，任何阶段 PR 不得由作者自行验收并合并，必须等待非作者正式审核。
